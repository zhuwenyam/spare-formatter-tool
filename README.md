# spare-formatter-tool

Backend developer · Rust and Actix

日常脚本的集中地

## 用法

```bash
cat data.txt | ./run.sh
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/spare-formatter-tool.git
cd spare-formatter-tool
chmod +x run.sh
```
